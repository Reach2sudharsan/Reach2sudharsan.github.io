# Graduate Student Website

A lightweight, responsive academic profile site built with plain HTML and CSS.
It works as a GitHub Pages site without a build step or JavaScript.

## Customize your site

Edit `index.html` to replace the sample profile details and bracketed prompts
with your own information. Update the page title and description in the `<head>`,
then add your research, publications, teaching experience, email, and profile
links. Remove any sections you do not need. Update the initials in the profile
mark to match your name.

Use `styles.css` to adjust the colors, typography, spacing, and responsive
layout.

## Preview locally

Open `index.html` in a browser, or serve the repository directory with any
static file server. No dependencies or build command are required.

## Publish with GitHub Pages

In the repository settings, open **Pages** and choose the branch and root
folder to deploy. GitHub Pages will publish `index.html` as the site homepage.
